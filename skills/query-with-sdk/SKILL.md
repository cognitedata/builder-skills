# Query with the Generated SDK

Use the type-safe SDK generated by `use-sdk-codegen` to read from your CDF data model at runtime.

## Prerequisite

Run **`use-sdk-codegen`** first. The generated files must exist under `src/generated_sdks/<name>/`.

---

## Step 1 — Find your generated SDK

```bash
ls src/generated_sdks/
```

Each subdirectory is one SDK. Its `index.ts` exports:
- `createSdk(client: CogniteClient): Sdk` — factory function
- `Sdk` — the fully-typed SDK interface
- Per-view operation types (re-exported)

---

## Step 2 — Instantiate the SDK

Pass your authenticated `CogniteClient` to `createSdk`. In a Flows app this typically lives in a hook or context:

```ts
import { createSdk } from '../generated_sdks/<name>';

// client comes from useDune() or AppSdkAuthProvider
const sdk = createSdk(client);
```

No network connection is made at instantiation — the SDK is a thin wrapper around in-process graphql-js execution backed by DMS.

---

## Step 3 — Query views

All generated methods are async and return typed results. Replace `<ViewName>` with the PascalCase name of your DMS view.

### List / filter / paginate

```ts
const result = await sdk.query<ViewName>({
  limit: 25,
  cursor: pageInfo?.endCursor,     // for pagination
  filter: {
    status: { eq: 'active' },      // typed filter input
  },
  sort: [{ field: 'createdTime', direction: 'DESC' }],
});
// result.items: ViewName[]
// result.pageInfo: { endCursor, hasNextPage }
```

### Get by instance ID

```ts
const item = await sdk.getById<ViewName>({
  instanceId: { space: 'my-space', externalId: 'asset-123' },
});
// item: ViewName | null
```

### Count

```ts
const { count } = await sdk.count<ViewName>({
  filter: { status: { eq: 'active' } },
});
```

### Full-text search

```ts
const result = await sdk.search<ViewName>({
  query: 'pump failure',
  limit: 10,
});
```

---

## Step 4 — Use in a React component or hook

Keep data fetching in custom hooks, not in components directly:

```ts
import { useEffect, useState } from 'react';
import { createSdk, type Sdk } from '../generated_sdks/<name>';
import { useDune } from '@cognite/cli/react';

export function useSdk(): Sdk | null {
  const { client } = useDune();
  return client ? createSdk(client) : null;
}
```

---

## Step 5 — Mock the SDK in tests

`test-helpers.ts` exports `makeMockSdk()` which returns a typed mock you can customise per test:

```ts
import { makeMockSdk } from '../generated_sdks/<name>/test-helpers';

const mockSdk = makeMockSdk({
  query<ViewName>: vi.fn().mockResolvedValue({
    items: [{ externalId: 'asset-1', status: 'active' }],
    pageInfo: { hasNextPage: false, endCursor: null },
  }),
});

// Inject via dependency injection — never import the real SDK directly in tests
renderHook(() => useMyHook(mockSdk));
```

---

## Done

The SDK queries run entirely in-process — no GraphQL server to stand up, no extra network hop. When the data model changes, re-run `npx @cognite/cli apps sdk generate <name>` and the TypeScript types update automatically.
